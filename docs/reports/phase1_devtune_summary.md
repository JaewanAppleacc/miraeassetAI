# Phase 1 평가데이터(DEV_TUNE 101문항) 결과 — 한 장 요약

재완이 공개한 Gold Phase 1 DEV_TUNE 101문항(207 중 봉인분 106 제외)을 내 구조로 끝까지
돌린 결과다. 검색·근거 단계는 LLM 없이 전수, 답변 생성은 HCX-005를 문항당 1회.
평가 원문은 이 저장소에 넣지 않았다(각자 재완 브랜치에서 받는다).

## 숫자 다섯 개

| | 결과 |
|---|---|
| 답변가능성 판정 (정답있음 / 코퍼스에 없음 / 공시유보) | **101 / 101 일치** |
| 지어낸 숫자 | **0건** |
| 정답 문서를 상위 20에 넣은 비율 (92문항) | **100%** |
| 정답 근거 슬롯을 상위 20에 넣은 비율 (270슬롯) | **97.0%** |
| 정답값 완전 포함 (정답형 92문항) | **63** (부분 18, 미포함 11) |

비용: 101문항 완주에 **346.92원**(VAT 별도). 35문항은 계산기·규칙이 답해 LLM을 부르지 않았다.

## 이 구조가 잘하는 것 (실측 근거)

**1. 없는 것을 없다고 한다.**
"삼성전기의 주요사항보고서가 코퍼스에 포함되어 있는가?" 같은 함정 5문항 — 문서 인덱스를
기업·유형·연도로 직접 세서 0건이면 `NOT_FOUND`. 비슷한 다른 공시를 대신 내밀지 않는다.
공시유보 4문항 — 원문의 유보사유·유보기한 칸을 찾아 `WITHHELD`로 답한다. 함정 9/9.

**2. 숫자를 지어내지 않는다 — 검증기가 실제로 잡았다.**
두산로보틱스 매출 변동 문항에서 HCX가 `-2171`이라고 답했다(정답 -20,060). 검증기가
"원문에 없는 수치"로 폐기하고 계산기 결과로 대체했다. 101문항 전체에서 이런 식으로
걸러낸 뒤 남은 날조는 0건이다.

**3. 계산은 코드가 한다.**
증감액·증감률·기업 간 차이·직전/이번 변동을 Decimal로 계산하고, 원 단위 값은 백만원
환산도 같이 낸다(팀 Gold 표기). 계산형 문항은 LLM을 부르지 않아 틀릴 자리도 비용도 없다.

**4. closed형(값 하나 찾기)에 강하다.**
CLOSED 66문항 정답값 완전 52, 수치조회(NUMERIC_LOOKUP) 55문항 중 47. 정답 문서는
CLOSED·OPEN 모두 100% 찾았다.

**5. 검색 코어를 건드리지 않고 고쳤다.**
101문항에서 나온 문제 9가지를 전부 agent 층(dart_detective)에서 규칙으로 해결했다 —
하이픈 날짜 조건, 코퍼스 존재 판정, 공시유보 판정, 항목 라벨 청크 보강(보유목적·정정
전후), dict 답변 직렬화, 계산기 트리거, 인용 doc_id 괄호, 백만원 환산, 표 인용 셀 대조.
그동안 gold25 검색 회귀는 매 라운드 +0.0000. 테스트 765개.

## 솔직한 한계

- **서술형·사건추적은 약하다.** NARRATIVE 20문항 중 완전 10, EVENT_TRACE 5문항 중 1.
  근거는 찾는데 문장으로 정리하는 건 LLM 몫이고, 프롬프트는 동결 상태다.
- **인용을 풀어 쓴 LLM 답 11건은 폐기됐다.** 숫자는 전부 원문과 맞았지만 "인용은 원문
  그대로" 규칙에 걸렸다. 이 규칙을 느슨하게 할지는 팀 결정 사항으로 남긴다.
- 비교·계산 12문항 중 완전 5 — 나머지는 3개월/누적 열 선택이 어긋난 경우다.
